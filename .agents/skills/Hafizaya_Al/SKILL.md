# Hafızaya Al

Kullanıcı kendisi, hobileri veya önemli kararları hakkında bir bilginin kalıcı
olarak hatırlanmasını açıkça istediğinde bu skill’i seç.

Çalıştırma çağrısı tam olarak şu biçimde üretilir:

`[CALL_SAVE_MEMORY: "Kullanıcı hakkında unutulmaması gereken bilgi"]`

Yalnızca kullanıcının açıkça kaydetmek istediği bilgileri kullan. Şifre,
API anahtarı, kimlik bilgisi, finansal veri, hassas sağlık verisi veya başka
kişilere ait özel bilgileri kalıcı hafızaya alma. Kullanıcı istemedikçe
çıkarım yaparak kişisel profil oluşturma.
